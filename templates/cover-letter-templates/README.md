# Cover Letter Templates

HTML/CSS templates for generating cover letter PDFs via Puppeteer.

## Usage

Say: `write cover letter for [Company/Role]`
Claude will use your master-experience.md and company research to write a tailored cover letter,
inject it into the active template here, and export a PDF to `exports/`.

## Adding Templates

Drop any `.html` file here. Same `{{COVER_LETTER_CONTENT}}` placeholder convention as resume templates.
